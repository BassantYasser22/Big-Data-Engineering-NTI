# Big Data Engineering NTI Training Program 🚀

This repository documents my journey in the **NTI Big Data Engineering 4-month training program**.  
It includes hands-on labs, assignments, and practical tasks throughout the course.

---

## 📚 About the Program

This training program focuses on building strong foundations in Big Data concepts and tools, including:

- Distributed data processing
- NoSQL databases
- Hadoop ecosystem components
- Real-world data engineering tasks

---

## 📂 Repository Structure

The repository is organized into the following modules:

- **MapReduce/** → Practical tasks using Hadoop MapReduce for distributed data processing
- **HBase/** → NoSQL database operations and hands-on HBase exercises
- **PySpark/** → Data processing and analytics tasks using Apache Spark & PySpark

---

## 🛠️ Technologies Used

- Hadoop MapReduce
- HBase
- Apache Spark
- PySpark
- Git & GitHub

---

## 📌 Learning Objectives

Throughout this program, I am learning and practicing:

- Processing large datasets using MapReduce
- Working with distributed storage systems
- Performing CRUD operations in HBase
- Building data transformations using PySpark
- Analyzing large-scale datasets with Apache Spark
- Understanding Big Data architecture fundamentals
